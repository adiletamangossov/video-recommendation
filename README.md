# Video recommendation

Content based рекомендации «Похожее» для каталога видео: фильмы, сериалы, шоу и выпуски шоу.
Пользовательские события не используются, похожесть считается только по метаданным каталога.

## Модель

Похожесть двух объектов это взвешенная сумма трёх косинусов:

    S = 0.55 * текст + 0.30 * жанры + 0.15 * персоны

- **Текст**: название и описание (fallback ru -> native -> en), TF-IDF на символьных n-граммах `char_wb (3, 5)`, затем TruncatedSVD на 256 компонент.
- **Жанры**: multi-hot, основной жанр весит 2, остальные 1.
- **Персоны**: актёры и режиссёры, multi-hot.

Штрафы:
- **хабовость**: `0.7 * hub_j`, где `hub_j` это среднее S кандидата по всем источникам группы. Так в топ реже попадают объекты, похожие на всё подряд;
- **возраст**: `0.01 * |age_i - age_j|` в годах возрастного ограничения.

## Правила выдачи

- MEDIABRAND -> MEDIABRAND: фильмы и сериалы рекомендуются вперемешку, шоу только шоу.
- VIDEO -> VIDEO: выпуски шоу рекомендуются только выпускам. Текст берётся свой, жанры, персоны и возраст от бренда шоу. Выпусков своего шоу в выдаче не больше 5, сам выпуск себе не рекомендуется.
- До 20 рекомендаций на объект, ранги идут подряд с 1.
- Одноимённые бренды с почти одинаковым описанием (похожесть описаний >= 0.75) считаются дублями и удаляются.

Все параметры лежат в `video_recsys/config.py`.

## Вход

Один файл каталога: CSV (разделитель определяется по заголовку), parquet, json или jsonl. По строке на объект, колонки:

`content_type` (MEDIABRAND / VIDEO), `content_id`, `mediabrand_id`, `video_category` (movie / series / video_show), `title_ru|native|en`, `description_ru|native|en`, `release_year`, `age_restriction`, `is_ready`, `genres`, `actors`, `directors`. В `genres`, `actors` и `directors` лежит JSON-массив объектов с полями `genre_id` / `person_id`; у жанров ещё есть `order`, основной жанр это `order = 1`.

## Запуск

    pip install -r requirements.txt
    python -m video_recsys.run --env prod --input catalog.csv --out out

На выходе:
- `recs_{env}_with_episodes.csv`: колонки `content_type, content_id, similar_content_type, similar_content_id, rank, score`;
- `recs_{env}_with_episodes_review.xlsx`: та же выдача с названиями, для ручного ревью.

В консоль печатаются диагностика и автоматические проверки: покрытие, целостность, совпадение группы, хабовость, распределение score, доля своего шоу. Если хотя бы одна проверка не прошла, процесс завершается с кодом 1.
